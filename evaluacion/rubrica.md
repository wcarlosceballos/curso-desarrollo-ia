# 📏 Rúbrica de Evaluación por Competencias

Escala: **Excelente (4)** · **Logrado (3)** · **En proceso (2)** · **Inicial (1)**

| Criterio | Excelente (4) | Logrado (3) | En proceso (2) | Inicial (1) |
|---|---|---|---|---|
| **Prompt ingeniería** | Prompt de 5 partes completo, conciso y produce resultado útil | Prompt completo pero mejorable | Prompt incompleto | No logra estructurar el prompt |
| **Uso de herramientas IA** | Elige el modelo/herramienta según Potencia-Velocidad-Coste | Elige herramienta adecuada | Usa siempre la misma sin criterio | No usa herramientas |
| **Configuración del entorno** | Crea commands, skill y MCP funcionales en `.opencode/` | Crea al menos commands y una skill | Crea solo commands | No configura nada |
| **Desarrollo SDD** | Spec EARS clara, plan, tasks y validación con tests | Spec y plan completos, faltan tests | Spec incompleta | Codifica sin spec |
| **Sistema multiagente** | Diseña coordinador + 3 subagentes con permisos coherentes | Diseña agentes pero permisos flojos | Enumera agentes sin permisos | No diseña el sistema |

**Instrumentos:**
- Portafolio digital (evidencias de cada competencia)
- Observación del trabajo con OpenCode
- Banco de preguntas (`evaluacion/preguntas.md`)
- Rúbrica de alineación DI (coherencia objetivos–contenidos–evaluación)
