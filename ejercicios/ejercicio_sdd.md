# 🧪 Ejercicio 2 — Spec-Driven Development

**Objetivo:** aplicar el flujo SDD de 7 pasos a una mini-app.

**Proyecto:** Diario de Estudio — app para registrar sesiones de estudio y rachas.

**Entregables:**
1. `specs/001-diario/spec.md` — requisitos en EARS (SI… ENTONCES…)
2. `plan.md` — archivos y funciones a crear
3. `tasks.md` — lista de tareas T1, T2…
4. Evidencia de pruebas (node --test o similar)

**Criterio de éxito:** cada requisito de la spec tiene su prueba correspondiente.
