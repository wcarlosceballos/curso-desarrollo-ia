# 🧪 Ejercicio 1 — Prompt Engineering

**Objetivo:** escribir un prompt efectivo de 5 componentes.

**Caso:** eres tutor de una maestría en educación y necesitas que la IA te ayude a crear una rúbrica de evaluación para un trabajo final.

**Tu prompt debe incluir:**
1. Rol
2. Contexto
3. Tarea exacta
4. Restricciones
5. Formato de salida

**Plantilla:**

```
Actúa como [rol].
Contexto: [situación].
Tarea: [qué necesitas exactamente].
Restricciones: [límites].
Formato de salida: [cómo lo quieres].
```

**Criterio de éxito:** la salida de la IA debe ser usable directamente como rúbrica.
